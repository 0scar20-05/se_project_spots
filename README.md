# Spots

A social media website that lets users edit their profile and publish image-based posts.

## Functionality

- **Full CRUD Card System**: Users can create, like, preview, and delete image-based posts with changes synced to the backend.
- **Responsive Modals**: Includes a preview modal for each post and a form modal for post creation.
- **Profile & Avatar Editing**: Allows users to update profile information and avatar images through modal forms.
- **Componentized Architecture**: Separates work using modular JavaScript (API handling, validation, helpers).

## Tech Stack

- HTML
- CSS (BEM methodology, responsive layouts)
- JavaScript (ES6)
- REST API integration
- Client-side form validation
- Modular architecture
